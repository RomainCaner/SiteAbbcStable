Mise à jour FFBB

Classements et rencontres récupérés depuis votre navigateur, puis publiés sur le site.

La FFBB bloque désormais les serveurs de GitHub : la mise à jour automatique n'aboutit plus. Cette page fait les mêmes requêtes depuis votre connexion, que la FFBB accepte. Rien n'est publié sans votre clic à l'étape 3.

1. Interroger la FFBB

Récupère les engagements du club et propose la poule de chaque équipe.

    2. Vérifier les poules, puis récupérer

    Le numéro d'équipe distingue SF1, SF2 et SF3 : vérifiez-le avant de valider. « Aucune » laisse l'équipe sur son encart « classement bientôt disponible ».

      3. Publier

      Un seul commit sur main avec standings.json, fixtures.json et teams.json ; le site se met à jour dans la minute. Il faut un jeton GitHub à accès fin, limité au dépôt SiteAbbcStable, permission Contents : Read and write (GitHub → Settings → Developer settings → Fine-grained tokens).

      Le jeton ne sert qu'à cet envoi : il n'est ni enregistré ni transmis ailleurs qu'à GitHub.

        Jetons FFBB pour la mise à jour automatique

        À copier dans GitHub → Settings → Secrets and variables → Actions → Repository secrets. Le workflow les utilisera — utile seulement si la FFBB laisse passer les données elles-mêmes depuis GitHub.
